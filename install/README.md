# Installing DX-DBiDigiModes V2R3

`DX-DBiDigiModes-V2R3-3.0.2-devel-win64.exe` is the Windows installer (64-bit Windows 10 / 11).

1. Download the installer and run it. Windows may warn that it is from an unknown publisher
   (the installer is not code-signed); choose *More info > Run anyway* if you trust it.
2. It installs to its own folder and adds Start menu and desktop shortcuts named DX-DBiDigiModes V2R3.
3. Settings are shared with WSJT-X (same settings folder), so run only one of the two at a time.
4. For the Microsoft Access log, install the free 64-bit *Microsoft Access Database Engine* if you
   do not have 64-bit Office. The MariaDB client is included in the installer.

The installer was built from the source in this repository (tag `V2R3`). This is not an official
WSJT-X release.
